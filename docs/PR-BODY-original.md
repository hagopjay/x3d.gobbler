# Bind Gobbler's domain feathers to Atlas evidence and execute one local foldback

Gobbler's original visual presents a compelling flywheel metaphor, but every counter is seeded synthetic data. This change adds an evidence observatory with twelve inspectable X3D feathers, snapshot-derived facts, digest-bound Atlas search, proposed domain contracts, and a clearly labelled teaching replay. It preserves the original cinematic and its audio.

The new offline evidence kernel validates graph identities, endpoints, historical output hashes, source pins, and bound foldback transitions. A separate executed structural shader guard turns archived failure `fm/1` into two negative fixtures, repaired and ordinary-URL controls, and a distinct authored Music consumer. The report carries source, code, and fixture digests. This is a local authored-fixture transfer; no shader compiler, renderer, or live repository integration is claimed.

## Reviewable changes

- `gobbler-flyte/index.html`, `observatory.css`, `observatory.js`: responsive controls and progressive evidence inspection.
- `build_observatory.py`, `observatory.x3d`, `observatory.json`: deterministic X3D scene, 12 proposed interfaces, shared meshes, named scene controls, Atlas and manifest digests.
- `flywheel-review/atlas/flywheel_kernel.py`, `snapshot_audit.py`, `shader_guard.py`, fixtures, and tests: portable, bounded evidence checks; no full-source import dependency.
- `ATLAS-INSIGHTS.md` and HTML reading edition: current snapshot status, operational architecture, domain contracts, measurable progress, failure modes, and bounded next PRs.
- `serve.py`, `verify.py`, standalone export builder, receipts, README: a reproducible local handoff.

## Limits and landing

This patch uses the supplied archive root as its base. It does not assert compatibility with the current HEAD of any external repository. The original historical witness and receipts remain intact; missing source helpers prevent full-source reproduction here. Browser rendering/interaction, XSD field validation, GPU performance, mobile rendering, and audio listening remain unverified. Generated animation is illustrative and is never presented as operational throughput.

No branch or pull request has been published. GitHub integration is disabled for this account, and no CLI authentication is present. Recommended first landing is a single reviewed observatory subtree in `x3d.demo`; lift the portable evidence helpers into the owner-selected Atlas/Loom repository after confirming the current layout and dependency policy. Follow-up work should complete one rendered real consumer transfer, restore full pinned-source reproduction, add bounded read-only MCP retrieval, then record human review.
