# Advance Gobbler with an intervention lab and rigorous evidence/execution boundaries

Gobbler's visuals could appear ready after a failed load, its workflow could
promote structural/path existence to broad `Confirmed` evidence, and offline
execution had paths toward live capabilities. This change fixes those
boundaries, repairs concrete X3D geometry/shader defects, and adds three
interactive experiments explaining what qualifies a flywheel return.

- Add the X3D Intervention Lab: byte identity/self-rebinding, discriminating
  positive/negative controls, and consumer identity/retry counting. Five actual
  Python shader-fixture observations feed byte-checked browser experiments;
  transfer rows remain explicitly synthetic.
- Harden Atlas/replay validation and duplicate-edge/ledger/Scene witnesses while
  retaining the archived Atlas and its historical receipts unchanged.
- Isolate Flyte offline/simulation modes; retain source provenance and explicit
  evidence facets; validate budgets/decisions; deduplicate usage IDs; improve
  memory replacement and checkpoint cleanup.
- Repair frontend lifecycle/readiness, reduced motion, tabs, media races and
  stale async work. Required standalone rewrite anchors now fail loudly.
- Repair camera singularities/aim, tether endpoints, nonplanar vanes, wheel-disc
  alignment, shader falloffs and URL encoding; rebuild both scenes and the
  standalone observatory deterministically.
- Add a pinned full X3D validation instrument, negative controls, actual Accrete
  integration, controller/geometry/export tests and a source-bound aggregate.
- Include an actual Blender 5.2.4 X3D import/render with measured gate/ring
  placement, plus the technical/creative review, field guide and ontology hooks.

Validation: `python tools/check_release.py` records the exact executed commands,
normal and `-O` suites, Node controls, full XSD/implemented semantics, actual
Accrete gate/admission, runtime/source identities and limitations in
`receipts/review-release.json`. The Blender receipt binds its own source,
instrument, tool and image. See `docs/IMPLEMENTATION-REVIEW.md` for disposition.

Native browser execution is blocked by this host's socket initialization;
`review-browser.json` is `not_run`. No fresh native pixels, audio listening,
shader compilation, GPU timing or performance claim follows from other checks.
The import still uses authored studio presentation and re-authored typography.

Cross-store exactly-once turns, concurrent spend reservations/hard invoice caps,
independent consumer adoption and measured scaling remain explicit follow-up
work. Existing historical runs are not relabeled as fresh experiments.
